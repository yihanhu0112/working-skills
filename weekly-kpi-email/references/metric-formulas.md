# 指标定义与计算口径

> 所有字段名、维度值、目标都来自 `config.yaml`。本文件只给公式和边界处理。

## 1. 周期归属

- 默认 ISO 周（周一至周日）。配置为周日起算时，先把日期整体平移一天再取周。
- 归属日期由 `columns.date_basis` 决定：
  - `approval`：审核/生效日期，适合新导入、补录的数据。
  - `business`：业务发生日期，适合历史分析。
  - 两者只能选一个，并在报告的数据说明里写明。
- 跨期记录（重复录入、补录、跨年项目）按用户指定的期间固定，不重复计入。
- 月初/月末的统计截止日要写清「截至 X 月 X 日」，不要默认整月。

## 2. 基础指标

| 指标 | 公式 |
|---|---|
| 本期金额 | Σ `amount`（按配置过滤后） |
| 单据数 | nunique(`document_id`) |
| 有效单据数 | 金额 > 0 的单据数 |
| 单均 | 本期金额 / 单据数 |
| 有效单均 | 本期金额 / 有效单据数 |
| 环比 | 本期 / 上期 − 1 |
| 同比 | 本期 / 去年同周期 − 1 |
| 维度占比 | 该维度金额 / 总金额 |
| 集中度 | 前 N 个实体的金额 / 总金额 |
| 客单价 | 金额 / nunique(客户)（若配置了客户维度） |

零金额单据（样品、赠品、红冲）计入单据数，但不计入单均；在数据说明里写明。

## 3. 目标与达成

| 指标 | 公式 |
|---|---|
| 期间累计 | 期间起始日至统计截止日的金额合计 |
| 期间目标 | 从目标表按「期间 × 维度」取；缺失时用上级目标按比例分摊并注明 |
| 达成率 | 累计 / 目标 |
| 时间进度 | 已过自然日 / 期间自然日 |
| 进度差 | 时间进度 − 达成率 |
| 缺口 | 目标 − 累计 |
| 剩余每周需完成 | 缺口 / (剩余自然日 / 7) |
| 需完成倍数 | 剩余每周需完成 / 本期实际 |

**双口径**：如果目标表同时有「公司总目标」和「各单元目标累加」，两个都要算，
并解释差异（目标是否层层加码、是否含未分解增量）。不要只报乐观的那个。

## 4. 趋势

- 取最近 4–5 周（可配置），算周均、最高周、最低周、本周位置。
- 判断增长来自「单量大」还是「单笔大」：分别看单据数环比和单均环比。
- 连续未达目标的周数要单独写，这是管理信号。

## 5. 排名

- 维度排名：按金额降序；同额按单据数降序；再同则按名称。
- 个人排名：期间累计目标、实际、达成率；列出前三和末三，不列全表。
- 排名变化：与上期比较，标出「新进」「掉出」「上升/下降 N 位」。

## 6. 多币种

- 只汇总统一币种金额列；原币金额单独保留。
- 需要折算时，用「月份 × 币种」汇率表，并在数据说明写明月均汇率。
- 同一张表出现多个汇率来源时，先按来源分组，差异归因为汇率口径，不直接判错。

## 7. 对账检查

出报告前必须通过：

1. Σ 各维度金额 = 总金额（允许 0.01 尾差）。
2. Σ 各周金额 = 期间累计。
3. 有效单据数 + 零金额单据数 = 单据总数。
4. Σ 各维度目标 = 总目标（或差额有解释）。
5. 每个百分比都能由表内数字复算。
6. 跨期记录没有被重复计入。

## 8. 常见边界

| 情况 | 处理 |
|---|---|
| 一单多行，金额只在首行 | 金额按行加；单据数去重；单均用去重后的单据数 |
| 一单多行，每行都有金额 | 先判断是「按比例拆分」还是「重复」；等值重复要去重 |
| 两人合作单分两行 | 视为按比例拆分，直接求和，不再去重 |
| 负数行 | 保留，标为红冲/退货；不参与单均时可排除并说明 |
| 缺日期 | 不计入周期指标；单独报缺失条数 |
| 缺金额 | 不按 0 参与合计；单独报缺失条数 |
| 合计行 | 聚合前删除 |
| 单号被 Excel 转成日期 | 只在能唯一还原时还原，其余列出待确认 |
| 导出窗口不一致 | 只对重叠窗口下结论，其余标「不可核验」 |
